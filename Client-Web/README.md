# Meshtrail Client-Web

Angular 22 front end. Normally started by the Aspire AppHost (see the [root README](../README.md)); standards for
humans and AI assistants are in [AGENTS.md](AGENTS.md).

```bash
npm ci
npm start        # http://localhost:3000, talks to the API at https://localhost:7301
npm run lint
npm test
npm run build
```

Requires Node 22.22.3+ or 24.15+.
